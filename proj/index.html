Reckless Drivin'

  • JavaScript
  • canvas
  • no dependencies

A browser port of Jonas Echterhoff's classic Mac OS game Reckless Drivin' (2000). The goal is to match the original exactly: the same 640×480 view, 60 Hz physics, AI, rendering and sound, drawn in software and copied to a canvas every frame. All ten levels are unlocked.

Blagger

  • HTML
