PlayStation 1 in OpenEmu

easy way to get a Playstation 1 emulator setup on a Mac

March 4, 2016 1 minute read

First, grab OpenEmu

To install the mednafen core, go to OpenEmu > Preferences > Library > Available Libraries and check the box for Sony Playstation:

Go find some PS1 BIOS files.

I'm not linking them for obvious reasons, but here are some links that might be helpful...

Check out good ole YouTube (and read some of the comments)

it keeps saying I need "scph 5502.bin" but whenever i drag it it just keeps telling me i need it:/

This one worked for me http://psxdev.net/downloads/bios/psx/SCPH5502.BIN

I downloaded my bios from here: http://www.emuparadise.me/biosfiles/PSX.zip Try with those ;). Rename scph7001.bin bios file to scph5501.bin just as I did. Now, copy scph5500.bin, scph5502 and the new scph5501.bin that you created renaming scph7001.bin in libary/application/suport/openemu/bios. Try and tell me how you go. Good luck.

Once you get the three BIOS files that OpenEmu is asking for, check to make sure the MD5 of each file matches what OpenEmu wants.

Link to OpenEmu's Github BIOS list

      Playstation (NA)

      Playstation (EU)

      32736f17079d0b2b7024407c39bd3050

This worked for me. If the MD5s match up, you'll have no trouble. The md5 of scph5500.bin from the initial download should match already...hint
